# 🏀 NBA Betting System

Complete ML system for predicting NBA games.

## Quick Start
```bash
pip install -r requirements.txt
python run_weekly.py
```

## Features
- 30 teams, 82 games/season
- Player props markets
- Pace-adjusted stats
- Quarter-by-quarter analysis

## Markets
1. Moneyline - Win/Loss
2. Spread - Point spread
3. Totals - Over/Under points
4. Player Props - Points, rebounds, assists
