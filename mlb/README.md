# ⚾ MLB Betting System

Complete machine learning system for predicting MLB games.

## Quick Start

```bash
pip install -r requirements.txt
python run_weekly.py
```

## Features
- 162 games per team = huge dataset
- Pitcher matchup analysis
- Ballpark factors (Coors Field, etc.)
- Weather impact on scoring
- First 5 innings betting
- Run line (spread) predictions

## Markets
1. Moneyline - Win/Loss
2. Run Line - Spread (±1.5)
3. Totals - Over/Under runs
4. First 5 Innings

## MLB-Specific Features
- Pitcher stats (ERA, WHIP, K/9)
- Team batting averages
- Ballpark factors
- Weather (temp, wind)
- Rest days
- Home/Away splits
